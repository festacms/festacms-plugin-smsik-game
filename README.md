# 🚀 Смсик: Космическая доставка

> Игра для страницы 404 FestaCMS — помоги Смсику доставить радость сквозь галактику!

[![Version](https://img.shields.io/badge/version-0.1.0-blue.svg)](CHANGELOG.md)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![FestaCMS](https://img.shields.io/badge/FestaCMS-1.0.0%2B-64C8BD.svg)](https://festacms.ru)

Мини-игра для страницы 404 сайтов на FestaCMS. Игрок управляет Смсиком — живым значком SMS-сообщения — и помогает ему доставлять поздравления через космос, уклоняясь от врагов и собирая бонусы.

Если игра отключена в настройках плагина — показывается обычная страница 404. Если включена — пользователь попадает в игру.

---

## ✨ Возможности

- 🎮 **Полноценная игра** прямо на странице 404
- 📱 **Мобильное управление** — свайп или наклон устройства
- 🖱 **Управление мышью и клавиатурой** на десктопе
- 🏆 **Лидерборды** — неделя / месяц / всё время
- 🛒 **Магазин** между партиями (жизни, оружие)
- 💖 **Система жизней** с бонусами
- ⭐ **Пауэрапы и оружие**
- 🎯 **Комбо-множитель** за серию бонусов
- 🌌 **Анимированный космический фон**
- 🥚 **Пасхалки**
- 🛡 **Встроенный фильтр имён** (мат, ссылки, email)

## 📦 Установка

### Через админку FestaCMS

1. Войдите в панель управления вашего сайта
2. Откройте раздел **Плагины**
3. Найдите **Смсик: Космическая доставка** в списке
4. Нажмите **Установить**
5. Плагин активируется — игра появится на странице 404

### Ручная установка

1. Скачайте последний релиз
2. Распакуйте в папку `plugins/smsik-game/` внутри директории админки FestaCMS
3. Установите через админку

## ⚙️ Использование

### Включение и отключение

В админке FestaCMS → **Плагины** → **Смсик: Космическая доставка** → **Вкл / Выкл**.

- **Вкл** → на странице 404 запускается игра
- **Выкл** → обычная страница 404 FestaCMS

### Управление в игре

| Платформа | Управление |
|---|---|
| **Десктоп** | Мышь / стрелки ← → / WASD. Пробел — стрельба |
| **Мобильные** | Свайп пальцем по экрану или наклон устройства |
| **Везде** | Esc — пауза |

## 📋 Требования

- **FestaCMS** — 1.0.0 или выше
- **PHP** — 7.4 или выше
- **MySQL** — 5.7 или выше
- **Современный браузер** с поддержкой Canvas 2D / WebGL

---

## 🛠 Технологии

- **Canvas 2D** (текущая версия)
- **Pixi.js** (планируется — для производительности на 4K)
- **Свои SVG-спрайты** — никаких эмодзи и чужих ассетов

---

## 🔒 Приватность

Плагин записывает в БД только:

- Игровое имя (введено игроком)
- Счёт, уровень, длительность партии
- Общие характеристики устройства (экран, браузер, ОС)

Данные **не покидают ваш сервер**. Никаких аналитических сервисов.
