# 🌌 Спарк: Космическая Доставка

> Игровой модуль для страницы 404 FestaCMS. Помоги Смсику Спарку доставить радость сквозь галактику!

[![Version](https://img.shields.io/badge/version-0.6.0-blue.svg)](CHANGELOG.md)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![FestaCMS](https://img.shields.io/badge/FestaCMS-1.0.0%2B-64C8BD.svg)](https://festacms.ru)

Игровой модуль, который превращает стандартную страницу 404 в мини-игру. Вместо ошибки «Страница не найдена» посетитель попадает в космическое приключение с героем Смсиком Спарком.

Если модуль отключён в настройках плагина — показывается обычная страница 404. Если включён — запускается игра.

---

## ✨ Возможности

- 🎮 **Полноценная мини-игра** прямо на странице 404
- 📱 **Мобильное управление** — свайп или наклон устройства
- 🖱 **Управление мышью и клавиатурой** на десктопе
- 🏆 **Лидерборд** — топ-10 игроков
- 🛒 **Магазин** между партиями (жизни, оружие)
- 💖 **Система жизней** с бонусами
- ⭐ **Пауэрапы и оружие** (15 секунд)
- 🎯 **Комбо-множитель** за серию бонусов
- 🌌 **Анимированный космический фон**
- 🔫 **Враги-стрелки** на высоких уровнях
- 🎼 **Синтезированный звук** (Web Audio API, без файлов)
- 🥚 **Пасхалки**
- 🛡 **Встроенный фильтр имён** (мат, ссылки, email)

## 📦 Установка

### Через админку FestaCMS

1. Войдите в панель управления вашего сайта
2. Откройте раздел **Плагины**
3. Найдите **Спарк: Космическая Доставка** в списке
4. Нажмите **Установить**
5. Плагин активируется — игра появится на странице 404

### Ручная установка

1. Скачайте последний релиз из [GitHub Releases](../../releases)
2. Распакуйте архив в папку `plugins/spark-game/` внутри директории админки FestaCMS
3. Установите через админку

## ⚙️ Использование

### Включение и отключение

В админке FestaCMS → **Плагины** → **Спарк: Космическая Доставка** → **Вкл / Выкл**.

- **Вкл** → на странице 404 запускается игра
- **Выкл** → обычная страница 404 FestaCMS

### Управление в игре

| Платформа | Управление |
|---|---|
| 🖥 **Десктоп** | Мышь / стрелки ← → / WASD. Пробел — стрельба |
| 📱 **Мобильные** | Свайп пальцем по экрану или наклон устройства |
| ⌨️ **Везде** | Esc — пауза |

## 📋 Требования

- **FestaCMS** — 1.0.0 или выше
- **PHP** — 7.4 или выше
- **MySQL** — 5.7 или выше
- **Современный браузер** с поддержкой WebGL

---

## 🛠 Технологии

- **Pixi.js** (WebGL) — рендер
- **Web Audio API** — синтез звуков и музыки
- **Свои SVG-спрайты** — никаких эмодзи и чужих ассетов
- **Vanilla JavaScript** — без фреймворков

---

## 🗂 Структура проекта

- **`game/index.php`** — точка входа (HTML + подключение JS)
- **`game/css/spark.css`** — стили игры
- **`game/js/spark-sprites.js`** — SVG-спрайты
- **`game/js/spark-config.js`** — конфиг + утилиты
- **`game/js/spark-audio.js`** — Web Audio (синтез)
- **`game/js/spark-ui.js`** — overlays, меню
- **`game/js/spark-core.js`** — игровая логика
- **`game/js/spark-main.js`** — точка входа JS

---

## 🔒 Приватность

Модуль записывает в БД только:

- Игровое имя (введено игроком)
- Счёт, уровень, длительность партии
- Общие характеристики устройства (экран, браузер, ОС)

Данные **не покидают ваш сервер**. Никаких аналитических сервисов.
